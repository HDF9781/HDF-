# 二中旮旯给木 · 放学后的约定

纯恋爱视觉小说原型，带完整主界面。

- 启动画面：HDF 动画（点击 / 空格可跳过），随后浮出游戏标题
- 女主角：照片立绘 + 3 张局部变形表情（微笑 / 难过 / 生气），配合滤镜、腮红、情绪符号、动作共 8 种状态
- 点击对话框 / 按空格推进时播放轻微点击音效
- 主界面：开始 / 继续 / 读取存档 / 设置 / 结局鉴赏 / 关于
- 剧本：序章 + 七章 + 终章 + 尾声，11 个选项、5 种结局、3 条岔路
- 系统：自动存档 + 3 个手动存档位、BGM / 音效音量、文字速度、自动间隔、结局收集
- 纯 HTML / CSS / JavaScript，零依赖、零外部素材

## 启动画面

页面加载后先播放 HDF 动画：字母逐个浮入、光环扩散，随后浮出游戏标题「二中旮旯给木」，再淡出进入主界面。点击画面或按空格 / 回车 / Esc 可立即跳过。嵌入时可用 `?splash=0` 关闭。

## 主界面

进入后先看到主菜单：

| 按钮 | 作用 |
| --- | --- |
| 开始游戏 | 从序章开始新游戏 |
| 继续游戏 | 读取最近一次自动存档；没有进度时禁用 |
| 读取存档 | 自动存档 + 3 个手动存档位 |
| 设置 | 文字速度、自动间隔、BGM 音量、音效音量，实时生效并保存 |
| 结局鉴赏 | 查看 5 个结局的解锁状态与说明 |
| 关于 | 操作说明、版本信息与「HDF制作，仅供娱乐」说明 |

右上角还有音效开关与全屏按钮；底部显示版本与操作提示。

### 存档

- **自动存档**：每推进一句台词自动记录，刷新页面或关闭浏览器后仍可「继续游戏」
- **手动存档**：游戏中按 Esc 或点「菜单」→「保存进度」，可写入 3 个存档位
- 存档包含：进度位置、好感度、分支标记、场景、表情、章节
- 全部保存在浏览器 localStorage，不依赖服务器

### 游戏内菜单

- 顶部「菜单」按钮或 `Esc`
- 返回游戏 / 保存进度 / 读取进度 / 设置 / 回到标题

## 故事与结局

学园祭前夜，她请你帮忙完成班级摊位「星空咖啡厅」的最后一块看板。

好感度初始 10，选项最高可加到 86。

| 最终选择 | 条件 | 结局 |
| --- | --- | --- |
| 「我喜欢你。」 | ≥ 80 | TRUE END · 烟火下的告白 |
| 「我喜欢你。」 | 75–79 | NORMAL END · 下次再说 |
| 「我喜欢你。」 | < 75 | BAD END · 错过 |
| 「明天也一起回家吧。」 | ≥ 75 | GOOD END · 朋友以上 |
| 「明天也一起回家吧。」 | < 75 | NORMAL END |
| 「……没什么。」 | ≥ 78 | NORMAL END |
| 「……没什么。」 | < 78 | BAD END |

### 分支

| 位置 | 选项 | 影响 |
| --- | --- | --- |
| 第三章 放学后的岔路 | 画材店 / 搬物资 / 河边 | 记录 art / class / play 标记 |
| 第七章 学园祭 | 小吃摊 / 舞台 / 摊位 | 记录 food / stage / stall 标记 |

SPECIAL END「夏日未晚」是隐藏结局：TRUE 路线 + 第三章选择「陪她去画材店」+ 尾声选择「牵住她的手」。

## 运行

直接用浏览器打开 `index.html`（建议 960×540 或更大窗口）。首次点击后 BGM 才会播放。

## 嵌入 galgame

```html
<iframe src="galgame-inner-minigame/index.html?name=操曾希"
        width="960" height="540" frameborder="0"></iframe>
```

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `name` | `操曾希` | 女主角名字 |
| `autostart` | `0` | `1` 时跳过主界面直接开始（启动画面结束后） |
| `splash` | `1` | `0` 时跳过 HDF 启动画面 |

### 通信协议

宿主 → 页面，开始一局：

```js
iframe.contentWindow.postMessage({ type: 'story_start' }, '*');
```

页面 → 宿主，抵达结局时：

```js
{
  type: 'story_complete',
  game: 'heart_vn',
  ending: 'true',     // true / good / normal / bad
  affection: 74,
  unlocked: 2
}
```
