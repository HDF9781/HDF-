# HDF 游戏创作展示网站

Win11 风格的游戏展示网站，展示「二中旮旯给木 · 放学后的约定」和「终端小游戏合集」。

## 文件结构
- `index.html` - 主页
- `src/win11.css` - Win11 风格样式
- `src/script.js` - 交互脚本
- `game/` - 游戏源码（已从 D:\DSH创造文件\galgame-inner-minigame 复制）

## 运行方式

### 方式一：直接双击打开
直接双击 `index.html` 文件，用浏览器打开即可。

### 方式二：本地服务器（推荐）
双击 `启动服务器.bat`，然后在浏览器访问 `http://localhost:8080`

## 功能
- 导航栏（首页、二中旮旯给木、终端小游戏、关于）
- 主页：欢迎页
- 游戏介绍：功能卡片 + 结局介绍
- 游戏嵌入：直接在浏览器中玩视觉小说
- 终端小游戏：展示 Python 小游戏列表
- 关于：DSH 介绍与统计

## 设计风格
- Win11 风格：浅色背景、圆角卡片、毛玻璃效果、流畅动画
- 首页动效：渐变漂移 + 浮动粒子动画
- 响应式布局：适配桌面和移动设备
- 悬停效果：卡片悬浮、按钮动画
